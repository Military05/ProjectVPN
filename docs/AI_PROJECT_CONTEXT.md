Этот файл предназначен для ChatGPT или другого AI-ассистента, который получает архив проекта в новом чате.  
Перед любыми правками нужно сначала прочитать этот файл.

## Главная цель проекта

Проект — это система продажи VPN-доступа через Telegram-бота и VLESS/Xray/3X-UI инфраструктуру.

Текущая цель:

1. Пользователь покупает доступ.
2. Админ или бот генерирует одну subscription-ссылку.
3. Клиент вставляет одну ссылку в V2RayTun / V2RayTan / Raytan.
4. В приложении появляется список каналов.
5. Каналы распределены по странам:
   - Нидерланды
   - Германия
6. В будущем каждый покупатель должен иметь индивидуальную ссылку и индивидуальные клиенты в 3X-UI.
