ЩЯ ССТ ЬЫХ Т:

ужно перейти от общей ссылки:
https://sub.sotervpn.ru/sub/soter

к индивидуальным объединённым ссылкам:
https://sub.sotervpn.ru/u/ivan
https://sub.sotervpn.ru/u/petr
https://sub.sotervpn.ru/u/alex

аждая индивидуальная ссылка тоже должна быть одной ссылкой для клиента.
нутри неё должны быть 15 каналов.

елаемая команда генерации:
python3 create_user.py ivan 100

де:
ivan = имя клиента / slug
100 = лимит трафика в GB

Система должна автоматически:
1. создать клиента в NL 3X-UI;
2. создать клиента в DE 3X-UI;
3. выставить срок 30 дней;
4. выставить лимит трафика;
5. создать файл /opt/sotervpn-sub/users/ivan.txt;
6. выдать ссылку https://sub.sotervpn.ru/u/ivan.

  ТЫ:

Так как VPS две, лимит ставится отдельно на каждой VPS.

апример:
100 GB на NL
100 GB на DE

актически клиент может использовать до 200 GB суммарно, если активно использует обе страны.
бщая централизованная квота на 2 VPS пока не реализована.

3X-UI API:

ля автоматического создания клиентов нужны:

NL_PANEL_BASE_URL
NL_PANEL_USERNAME
NL_PANEL_PASSWORD
NL_INBOUND_ID

DE_PANEL_BASE_URL
DE_PANEL_USERNAME
DE_PANEL_PASSWORD
DE_INBOUND_ID

еальные значения не хранить в GitHub.
спользовать .env на VPS.
 GitHub можно хранить только .env.example.
